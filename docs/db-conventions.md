# 数据库规范

## 1. 命名规范

- 表名：`snake_case`，建议带业务前缀
- 字段名：`snake_case`
- 主键：统一使用 `id`（特殊业务键按领域规则补充）
- 时间字段：`created_at`、`updated_at`

## 2. 通用字段（建议）

- `id`
- `created_by`
- `created_at`
- `updated_by`
- `updated_at`
- `deleted`（若采用逻辑删除）

## 3. 索引规范

- 根据真实查询路径设计索引
- 对自然唯一键建立唯一索引
- 避免冗余索引与重叠索引

## 4. SQL 规范

- 生产 SQL 禁止 `select *`
- 明确列名，控制返回字段范围
- 高频接口避免全表扫描
- 批量操作需要有数量控制

## 5. 事务规范

- 事务范围尽可能小
- 长事务中避免远程调用
- 明确定义业务异常回滚策略

## 6. 变更规范

- 表结构变更需版本化管理并可评审
- DDL 尽量具备幂等性
- 关键变更需配套回滚脚本
